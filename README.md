# ApplyTrack

ApplyTrack is a simple job application tracker that helps users organise and keep track of the jobs they have applied for. It is useful for students and job seekers who want an easy way to manage their applications in one place.

## Live demo

[Try ApplyTrack](https://farhan-ad.github.io/ApplyTrack/)

## Features

- Add new job applications
- Update application statuses
- Delete applications
- Search applications by company or job role
- Save application data in the browser

## How to run

1. Open the project folder in VS Code.
2. Make sure the Live Server extension is installed.
3. Open index.html in VS Code.
4. Right-click index.html and select **Open with Live Server**.
5. The project will open in your browser and you can use the application.

## Data storage

- Applications are saved using localStorage, so they remain saved even after refreshing the page.
- Saved application data belongs to the browser and the specific site address where the project is running.
- Applications do not sync between different devices or browsers.
- Clearing the site's browser data will remove all saved applications.
